# Still Garden

A dependency-free CSS Zen Garden-inspired study. The same editorial content can be viewed through four visual themes, alongside an interactive Japanese-inspired gravel garden.

## Run

Open `index.html` in a modern browser. No build step, server, package installation, or internet connection is required.

## Controls

- Drag on the garden with **Rake** selected to draw gravel lines.
- Click with **Stone** or **Moss** selected to place an element.
- **Undo** removes the last gesture; **Reset** clears your additions.
- **Daylight** changes the garden to evening light.
- Choose **Stillness**, **Verdant**, **Earth & ink**, or **Moon garden** to restyle the page without changing its content.
- Keyboard users can select a tool with Tab, focus the garden, then press Enter or Space to use it at the centre.
